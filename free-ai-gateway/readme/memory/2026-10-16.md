## 调研：dsh-our-free-model 项目 + Cursor 接入可行性

用户提到"dsh-our-model"，实际真名是 `dsh-our-free-model`（GitHub 上无前者）。现挂 `Ebony-Vinyl/dsh-our-free-model`，原作者 zouyuxuan122，MIT，~18.3k stars。

**项目性质**：dsh（DeepSeek Harness）插件，非独立工具。起本机转发网关 `127.0.0.1:18899`，同时讲 OpenAI Chat/Responses 与 Anthropic Messages 协议。

**模型来源分五类**（源码 `src/providers/index.js` 模块注释 + README）：
1. 公共免密车道：OpenCode Zen（`Authorization: Bearer public` 写死）、Kilo（无凭据）
2. 账号渠道 ×13：CodeArts/CodeBuddy/Qoder/TRAE/Cline/Loomy/Raccoon/MiniMax/ZCode/Gemini 等，各自挂本地网关 `127.0.0.1:8326`，需登录+领积分
3. 聚合提供商 ×76：`src/providers/registry.json` 内置，分类 `apikey|free|free-tier|oauth|local`，含 OpenRouter、Ollama、LM Studio
4. 本地本源：Ollama / LM Studio / llama.cpp
5. EAC 协付车道：仅两个桌面宿主，需 GitHub star 解锁

**自定义源的关键结论**：不能新增第 77 家。`registry.json` 是仓库内置的，`parseProviderModelId()` 用 `BY_ID.has(providerId)` 校验前缀，未知前缀直接返回 null。format 仅支持三种枚举（openai-chat / openai-responses / anthropic-messages）。但**可以覆盖已注册条目的 baseUrl + 模型清单**（部分条目有 `baseUrlOverrideEnv`），等效于借壳接入自建端点。

**Cursor 接入结论**：技术上可行但代价高。Cursor 的模型请求由服务端发出（api2.cursor.sh 拼 prompt），localhost 在服务端解析 → 必须公网 HTTPS 隧道 + key 校验。仅 Chat/Agent 走自定义端点，Tab 补全永远用 Cursor 自有模型。Agent 模式有已知 bug（子任务静默降级、model 字段丢失）。BYOK 不享 ZDR。建议：VS Code + Cline/Continue（本地扩展，零隧道）或 Claude Code/Codex 直连。

**核心洞察**：能否接本地网关取决于 harness 架构——模型调用从本地进程发出（Claude Code/Codex/VS Code 扩展）还是厂商服务端代理发出（Cursor）。

## 实测：两条公共免密车道的真实可用性（2026-10-16）

**结论：Kilo 可用，OpenCode Zen 不可用。**

- **Kilo AI 公共网关**（`https://api.kilo.ai/api/gateway`）：✅ 完全可用。免凭据（不带头即可，带假 key 反而 401）。免费池 15 个模型（`isFree: true`）。chat/completions、/v1/messages（Anthropic，含 thinking + tool_use）、流式 SSE、工具调用全部通过。偶发超时（nemotron-3.5-lightning、openrouter/free 各测出 45s timeout）。
- **OpenCode Zen 免费车道**：❌ 403。两层门禁：
  1. `FreeTierError` —— 客户端指纹门禁（"can only be used from within OpenCode"）。已按其源码复刻 UA `opencode/1.18.31` + `x-opencode-client:cli` + `x-opencode-session-id` + 铸造形状 session + bash/read 工具指纹，Python 与 Node 两栈均仍 403。UA 版本、header 组合全扫过，无效。上游 2026-10-13/14 收紧，插件 10-15 才修。
  2. `RegionError` —— 本机出口 IP 为**中国河南郑州 AS4837 联通**，`cat-jam-free` / `muse-spark-*` 直接返回 "not available in your country"。
  → 结论：地区门 + 指纹门双重拦截，本机不可用。这也解释了为什么 Zen 上挂着 claude-opus-5 / gpt-6 这些顶级模型却拿不到。

自建零依赖 Node 网关（`kilo-free-gateway/server.js`，默认 `127.0.0.1:8899`），把 Kilo 免费池转成本地 OpenAI + Anthropic 双协议端点。E2E 验收全绿：/healthz、/v1/models、非流式、流式(55 SSE 行)、Anthropic /v1/messages(thinking + tool_use)、OpenAI 工具调用(tool_calls)。支持 `LOCAL_KEY` 本机口令。
